# MediAgenda

Aplicação Android genérica para gestão de medicação e agenda médica.

Este projeto é compilado automaticamente pelo GitHub Actions. O código-fonte de trabalho é reconstruído a partir dos ficheiros em `source/` para permitir o build automático sem Android Studio local.

SHA-256 do ZIP de origem: `f6c464cbd5025f8f478283db20e17ac8b71b9428dfec9f0e4a60295b95f54a77`

O APK de debug é publicado como artefacto do workflow **MediAgenda Android Build**.
