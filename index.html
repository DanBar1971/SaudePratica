Como instalar a APK no Android ou Xiaomi?
  1. Descarrega a APK pelo botão acima, diretamente do GitHub Releases oficial.
  2. Abre o ficheiro SaudePratica.apk em Downloads, no navegador ou na app Ficheiros.
  3. Se o Android impedir a instalação, toca em Definições no aviso. Em alternativa, pesquisa por Instalar apps desconhecidas nas Definições do telemóvel.
  4. No Xiaomi/HyperOS, o caminho pode ser Definições → Definições adicionais → Privacidade → Acesso especial a apps → Instalar apps desconhecidas. Noutros modelos surge em Proteção da privacidade → Permissões especiais.
  5. Escolhe a aplicação que abriu a APK (por exemplo, Chrome ou Ficheiros) e ativa Permitir desta fonte. Volta ao ficheiro e toca em Instalar.
  6. Depois da instalação, podes voltar a desativar Permitir desta fonte.

Importante: atualiza por cima da SaúdePrática existente, sem a desinstalar, para conservar os dados. Faz primeiro um backup. Autoriza apenas fontes em que confias; se o Android mostrar outro bloqueio de segurança, lê o aviso e não desatives a proteção geral do telemóvel.

Para atualizar, instala por cima da versão anterior. Faz primeiro uma cópia de segurança dos teus dados e não desinstales a aplicação.
DÚVIDAS FREQUENTES

Perguntas e respostas.

Informações importantes sobre a instalação, os alertas e as funcionalidades da SaúdePrática.

É necessário desinstalar a versão anterior?

Não. Para preservar os dados, instala a nova APK por cima da versão anterior. A aplicação utiliza o mesmo identificador e certificado de assinatura. Faz uma cópia de segurança antes de atualizar.

O alarme aparece sempre em ecrã inteiro?

A app utiliza notificações de alta prioridade e o mecanismo de alarme em ecrã inteiro do Android. No Android 14+ e no Xiaomi/HyperOS, o sistema pode apresentar apenas uma notificação destacada quando o telemóvel está desbloqueado. É importante autorizar os alarmes exatos, as notificações em ecrã inteiro e a execução em segundo plano, quando disponível.

Preciso de uma chave Gemini para a Nutrição?

Sim, apenas para analisar fotografias com IA. A Nutrição também permite introduzir os alimentos manualmente sem utilizar o Gemini.

  1. Abre o Google AI Studio — API Keys e inicia sessão com a tua conta Google.
  2. Se já tens uma chave válida, podes utilizá-la. Caso contrário, escolhe Create API key.
  3. Seleciona ou cria um projeto Google Cloud e copia a chave para um local privado.
  4. Na SaúdePrática, abre Config/Opções → Gemini · API Key e teste, introduz a chave e testa a ligação.
  5. Para verificar a quota disponível e os modelos autorizados, abre o Google AI Studio — Rate Limits.

Se aparecer o erro 429, a quota ou limite do projeto pode ter sido atingido. Criar outra chave no mesmo projeto não aumenta a quota. O erro 503 costuma indicar indisponibilidade temporária do serviço. Nestes casos podes continuar a registar a refeição manualmente.

Segurança: nunca partilhes a API key nem a coloques num website público ou num repositório GitHub.

Posso gerir a saúde de vários familiares?

Sim. A aplicação permite organizar informações em perfis separados, com funcionalidades para cuidadores e opções de sincronização familiar.

Este site recebe os meus dados de saúde?

Não. Esta é apenas uma página pública de apresentação e download. Não contém formulários de dados clínicos nem permite ver os registos guardados na aplicação.
